# Profile geometry pilot

`geometry_pilot.npz` preserves the 30 original trial records from the local
`dropout-pilot-results` directory. It includes their configurations, independent
random streams, curves, split identities, and original provenance.

The pilot contains three seeds for each of ten profiles. It is validation-only:
no test comparison or completed width-transfer result can be inferred from it.
The original scale-transfer protocol remains in `experiments/scale_transfer/`.
